# Лаборатория Simplify

`npm run simplify:lab` запускает локальный интерфейс на http://127.0.0.1:4179. `-- --port 0` выбирает свободный порт. Сервер доступен только через loopback и отдаёт фиксированный набор ресурсов. Загруженные пользователем изображения остаются в браузере.

Лаборатория собирает текущие `offscreen/simplify/worker.ts`, `offscreen/simplify/service.ts` и `workflows/simplify/compute-client.ts` через установленный esbuild. Копии алгоритма здесь нет. Worker выполняется вне основного потока. Изменения исходников требуют перезапуска сервера. JSON содержит хеши исходников, бандлов, конфигурации, источника, параметры, область, версию и время обработки. Этот режим проверяет вычисления, но не полномочия background runtime расширения.

Выберите эталон или загрузите изображение, задайте область в пикселях и параметры. Нажмите «Обработать». Сравните изображения, проверьте роли элементов, целостность, остатки текста и стиль. Запишите оценку и скачайте JSON. Оценка по умолчанию — «Не проверено»: успешное вычисление не означает хорошее качество. Кнопка PNG сохраняет полное изображение с обработанной областью. Отмена сохраняет последний принятый результат. Замена источника сбрасывает результат; запоздалый ответ не может его заменить.

Три публичных синтетических SVG принадлежат этому инструменту. `fixtures.json` содержит роли и прямоугольники `[x, y, width, height]`. Это справочная разметка для ручной оценки, а не автоматический критерий качества.

`npm run simplify:check` проверяет три эталона и пять сочетаний параметров через настоящий Worker, выгружает PNG, отчёт и снимки интерфейса в `.tmp/simplify-lab-results`. Проверяются оба основных viewport и границы адаптивных правил. Оценки качества остаются непроверенными. `node --test tooling/simplify-lab/server.test.mjs` проверяет ограничения сервера.

Для приватного набора явно передайте `--corpus /absolute/path/no-ocr/corpus.json`. Манифест содержит `cases` с `id`, `path` и SHA-256 `sourceHash`. Пути разрешены только внутри родительского каталога каталога манифеста; символические ссылки проверяются после разрешения. Сервер проверяет PNG и хеш каждого файла до запуска. Старые результаты из манифеста не используются как текущий алгоритм. Приватные изображения и отчёты нельзя добавлять в Git.

Проверка по умолчанию ограничена тремя публичными случаями даже при подключённом корпусе. Полный набор запускается только явно: `npm run simplify:check -- --corpus /absolute/path/no-ocr/corpus.json --full`. Параметр `--out` выбирает каталог результатов. Полная матрица здесь означает пять репрезентативных сочетаний для каждого случая, а не декартово произведение всех параметров.

Для проверки текущего инструмента в приложении сначала выполните `npm run qa:e2e:build`, затем `SNIPTALE_EXTENSION_BUILD_DIR=.tmp/e2e-builds/test npm exec playwright test -- tooling/test/e2e/extension-critical/extension-critical-simplify.spec.ts --workers=1`. Сценарии проверяют редактор, страницу, обрезку и запись при 1280×560 и 1920×900. В редакторском стенде замоканы платформенные операции хранения и сохранения; вычислительные запросы передаются настоящему расширению. Остальные поверхности используют настоящие маршруты захвата и Worker расширения. Проверяются фон, изменение текста, геометрия полос после изменения размера, форма ручного значка, сведённый снимок и пиксели декодированной сохранённой записи.

Обычный запуск не изменяет Worker и не открывает диагностические документы. Для разбора несоответствия координат доступен явный `SNIPTALE_SIMPLIFY_OBSERVE=1`: наблюдатель внутри принадлежащего расширению offscreen-документа сохраняет переданные PNG, параметры, область и ответ Worker в каталог результатов Playwright. Он не изменяет сообщения и не записывает capabilities. Этот режим предназначен для диагностики; итоговую проверку выполняйте без него.
